## 调试和修复 401 错误的计划

### 第一步：使用 curl 测试后端 API
1. 启动 nushell 并登录获取 token
2. 测试 `/auth/login` 接口确认能正常获取 token
3. 使用获取的 token 测试三个接口：
   - `POST /change-password`
   - `POST /users`
   - `POST /operation-logs/revoke/:id`

### 第二步：根据测试结果确定问题
- **如果后端测试成功**：问题在前端，需要检查 `getAuthHeaders()` 或 token 存储逻辑
- **如果后端测试失败**：问题在后端，需要检查认证中间件或 token 验证逻辑

### 第三步：修复问题
根据第二步的测试结果，修复相应的问题：
- 前端问题：修复 `index.html` 中的 token 处理逻辑
- 后端问题：修复认证中间件或路由配置

### 第四步：验证修复
使用浏览器测试三个功能是否正常工作
